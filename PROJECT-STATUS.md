## Where I am
**2026-08-28 (round 2) — `*amend-docs` made private and corporate repositories reachable (F-IMPORT, Phase 3).** Today TfLens can only read **public** repos, and BRD-100 refused a private one outright with no alternative — a corporate user had no path at all. **BRD-131..BRD-141** add a second way in: the Add-source dialog on `/repos` opens on a **mode fork** — *Fetch via API* (public repos, the existing path) or **Import metric files**, where the user uploads the telemetry their framework already wrote to disk. **TfLens never needs a credential, a network route to the repo, or any change to the repo**, and neither framework is asked to grow an export command. Owner decision the same day: **folded into the Repos screen, not a separate `/import` route**, so the two ways of adding a source sit in one dialog and the demarcation is visible in one grid (`Synced` / `Imported` column) — which also meant no nav item changed and no other mockup moved.

Three decisions inside it are worth knowing about. **The uploaded bundle's sha256 stands where a commit SHA stands** (ADR-022) — including for parity pinning, where it is *stronger*, because the operator runs the reference over the identical bytes instead of re-cloning and trusting the result matched. **Origin is displayed everywhere and pools nowhere** (ADR-021): a record means the same thing whichever way it arrived, so making it a fifth segmentation axis would halve every figure for no gain — it gets a badge, a Coverage column and a `source_kind` export key instead. And **an imported source gets `Re-import`, not `Sync`**, with the poller skipping it entirely — a greyed-out Sync button would be a lie about what the row can do. **Two out-of-scope lines were amended rather than quietly broken** ("private GitHub repos" and "any ingestion endpoint"); the upload is an authenticated file-picker, bounded in code (BRD-139), and remains the only inbound path. `TelemetryImportService` previews before it commits and **refuses a precomputed rollup** (BRD-140) — importing conclusions instead of evidence is exactly how a plausible wrong number would get in. **No code changed.**
