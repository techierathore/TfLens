Written by the analyst during *amend-docs TfLens. Documents only; no code; nothing committed.

Words used below:

  • the reference script — .tfcore/telemetry/tf-metrics.sh, the framework's report script. TfLens's parity check compares TfLens's figures against it key by key, and it is never edited.
  • Sample app — a made-up project (app id SampleApp) that exists only as test files in this repository. It is not a real repository and is never connected to anything.

First amendment — applied#

Phase 4, Estimates: BRD-211 to BRD-219, nine checklist rows, docs/mockups/estimates.html and estimates-playbook.html, Architecture §5.9, §6.x and ADR-034 / ADR-035, appPhase: 4, BRD-89 extended to the estimate separation. Two figures are not computed by the reference script, so they are hand-checked once: the Total row (build + machine QA) and the per-row actuals (BRD-217).

Second amendment — proven on the Sample app, not on a real project (applied 2026-11-10)#

TfLens is public; no private project's figures or name go into it. Every figure and every mention of the private project in the phase 4 documents, the two mockups and PROJECT-STATUS.md is replaced by the Sample app. No real repository's estimates are needed: they appear on the page by themselves when a public repository carries an estimates.jsonl (TfLens's own first).
