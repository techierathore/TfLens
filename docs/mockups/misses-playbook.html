The Playbook's reporting guards are stricter than the TechieFlow stream's, and they are not relaxed to match it

A model or tier attribution requires origin_confidence: "linked" and a complete valid source window and a non-null observed model. A headline repair token or cost figure additionally requires cost_attribution: "sole" and cost_status: "complete". An inferred or unknown origin is never placed in an “unknown model” bucket — a bucket named for a model is a claim about a model, and these records do not support one.

These two columns are side by side and never summed, merged or charted together — the same rule, and the same reason, as phase_gate versus gate. A process gate says which stage of the method caught it; an assertion gate says which check fired. Adding them would count one miss twice and mean nothing.
