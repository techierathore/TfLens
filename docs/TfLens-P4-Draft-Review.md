# TfLens — Phase 4 build, and what became of the 11 November draft

Written 2026-11-12 by the build of phase 4 (Estimates). Nothing is committed.

## How the draft was read

Git is off limits to agents here, so the draft was not diffed against the last commit. Instead, the
other model's own session record (OpenCode's local database) was read: it holds every edit that model
made, old text and new. Every changed file was then read against the phase 4 requirements and the
Architecture. Before any change, the draft built cleanly and all 1,042 .NET tests passed. That only
showed the draft agreed with its own tests.

## Kept as written

- The stream end to end: the record type, the parser, the dedupe on the BRD key, the store reads and
  writes, the importer and sync counts, and remove-repository and rebuild through the shared stream list.
- The reconciliation engine (`EstimateMetrics`) and its result types. They were checked line by line
  against the framework's script. Its reference outputs were regenerated by running that script, and
  they match the draft's copies byte for byte.
- The export block, the `estimates_extras` allow-list entry and the coverage check in
  `tools/parity-compare.py` (BRD-218 asks for both).
- The draft's hand check of the Totals and per-row figures. It was redone from the raw files with a
  separate script, and every figure matched.
- The sidebar item and the ten-item order in the shell test.

## Redone

- **Numbers on the page** went through the platform's own rounding, which differs from the script's on
  ties (1,250 tokens printed `1.3k`; the script prints `1.2k`). A shared port of the script's two
  formatters now does it, pinned by 29 cases generated from the script itself.
- **Token ranges** read `42.0k (28.0k–56.0k) tok`; the design and §3.1 read `42.0k tok (28.0k–56.0k)`.
- **Actual figures** skipped the one component every figure must pass through.
- **Every card appeared twice** when two loads overlapped (seen with All repos picked).
- **The By row table** was cut off at the card's left edge (`EQ-FN-001`).
- **No test had a row id in its title**, so a verify would have left all of them out. No browser test
  existed for the page at all.
